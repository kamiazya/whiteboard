# How-to guides

Goal-oriented recipes. Each how-to assumes you already know the basics and want to accomplish
one specific task. For a guided first run, start with the [Tutorials](../tutorials/).

Planned guides (added in a later migration slice):

- **Configure an MCP client** — point Claude Code or Codex at Whiteboard.
- **Run the local daemon** — start the loopback daemon for agent workflows.
- **Self-host with Docker** — run Whiteboard in server mode for a team.
- **Use templates** — insert and parameterize reusable canvas fragments.
