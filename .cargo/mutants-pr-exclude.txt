# The mutants the in-diff gate (`rust:mutants:pr`) does not judge, one glob a
# line, each a path under the repository root. `rust-mutants.mjs` passes them to
# cargo-mutants as `--exclude` in `pr` mode only: they are NOT in
# `.cargo/mutants.toml`'s `exclude_globs`, which cargo-mutants applies to every
# run, so `rust:mutants:full` judges these files and a push is the only place
# they are left out.
#
# The vendored markdown-rs parse path (about 32,000 lines) is judged by its
# regression tests, its fuzz target, the remark oracle that follows it and the
# full run, not in-diff: its 2,531 mutants at about 54 s each are far past four
# 40-minute shards. The code written for it here stays judged in-diff: `lib.rs`
# and `limits.rs`, `autolink.rs` (the second literal-autolink pass), and the
# three files under `vendored/` that are ours (`budget.rs`, `tree_text.rs`, and
# `util/edit_map.rs`, rewritten as a BTreeMap), so they are left out of this
# list. A glob cannot except a file, hence the list. An entry naming no file
# fails the script, so the list cannot outlive the code it names.
